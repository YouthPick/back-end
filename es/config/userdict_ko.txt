# nori 사용자 사전
#
# 형식 두 가지
#   단어              → 하나의 명사로 인식만 시킨다
#   단어 조각1 조각2   → 복합어로 등록하고 분해 방식을 지정한다
#                       (조각을 이어붙이면 원본과 정확히 같아야 한다)
#
# decompound_mode: mixed 와 함께 쓰면 원본 + 조각이 모두 색인된다.
#   청년농업인 청년 농업인  →  [청년농업인, 청년, 농업인]
#
# 이 파일을 고치면 재색인이 필요하다(색인 시점에 적용되므로).
#
# 후보 추출: es/helper/dict_candidates.py 로 정책 제목 2,691건을 분석해
# "3조각 이상 + 한 글자 토큰" 인 단어를 뽑았다(등장 3회 이상, 88개 중 선별).
